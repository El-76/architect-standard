|  +R4   | Данные пользователей в Интернет-банке должны быть защищены шифрованием<br>**Примечание**: скорее всего это уже так и есть                           |              |

| +R7    | Использование новых технологий допустимо с учётом того, чтобы они были совместимы с существующими платформами разработки, а также чтобы внутри банка уже была экспертиза                           |              |

| +R13 | В качестве инструмента реализации требований по доступности можно использовать равномерное горизонтальное масштабирование и распределение запросов между серверами и приложениями и ЦОД, однако нужно учитывать, что текущая АБС может масштабироваться только вертикально из-за своей базы данных |
